# Legacy Vault Frontend

A clean and simple frontend for **Legacy Vault**, a decentralized crypto inheritance application built on Ethereum Sepolia.

## Features

- Connect and disconnect your wallet
- View vault balance
- View vault status
- View owner, beneficiary, and guardian addresses
- View inactivity timeout and grace period
- Perform a proof-of-life check-in
- Deposit ETH into the vault
- Set a beneficiary address
- Set a guardian address
- Claim funds when the vault becomes claimable
- Responsive interface for desktop and mobile

## Tech Stack

- React
- Vite
- Wagmi
- Viem
- CSS
- Ethereum Sepolia
